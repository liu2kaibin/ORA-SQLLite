# `v0.1.0` developer preview

## Release identity

The release contract is a GitHub developer pre-release tagged `v0.1.0`, crate version `0.1.0`, on-disk format 2, and MSRV 1.85. It is not published on crates.io. This documentation commit does not create a tag or GitHub release.

## What developers can do

Developers can use the synchronous embedded Rust API to create or open a database, prepare parameterized CRUD statements, pull typed rows, use auto-commit or explicit read/write transactions, enforce the documented constraints, store the supported Oracle-oriented scalar values, and reopen format-2 files. Start with [Getting started](../getting-started.md) and the executable examples linked there.

## `v0.1.x` compatibility

Within the `v0.1.x` patch line, documented public types, methods, parameter conventions, and numeric `ErrorCode` values remain source compatible. Format-2 databases created by `v0.1.0` remain readable and writable, including existing V1 records within format 2. Optional Oracle error metadata may be added where absent without changing the stable error category, fatality, or successful behavior. Diagnostic message text and execution plans are not stable contracts.

## Validation evidence

Phase 6 branch validation and the hosted Release Preview have not yet executed at this documentation commit. No validation success is asserted by this intermediate note; observed command results will replace this statement during final release validation.

## Known limitations

See the [three-state compatibility matrix](../oracle-compatibility.md). In particular, there is no network server or Oracle wire protocol, PL/SQL, async API, ORM integration, multi-process access, named timezone support, sequences, pagination, or SQL outside the stated subset.

## Scale evidence boundary

The approved MVP scale maximum is 100,000 rows. A prior run reached 4.7 million committed rows and 18.286 GiB of owned temporary database/WAL data before manual stop; that is retained partial evidence only. There is no completed 10-million-row PASS claim.

## Upgrade expectations

Patch releases in `v0.1.x` follow the compatibility promise above. A breaking public Rust API or on-disk format change requires at least `v0.2.0` and written migration notes. Consult the [changelog](../../CHANGELOG.md) before upgrading.
